# Assignments

There are three assignments and a final project.

- **[Assignment 1: Screen Reader Familiarization](./a1/)**, due September 9. Learn to operate a screen reader well enough to evaluate interfaces with it.
- **[Assignment 2: Accessibility Auditing and Remediation](./a2/)**, due October 7. Evaluate an interface against WCAG, test it with a screen reader, and implement fixes.
- **[Assignment 3: Non-Visual Design](./a3/)**, due October 28. Design and build a structured non-visual interface.
- **[Final Project](./final/)**, proposal due November 4 and presentations November 30 through December 4.

## Technical expectations

To complete assignments, you will write HTML, some CSS, and some JavaScript. You need a text editor, a browser, and a screen reader.

Students enter this course with a wide range of programming experience, and I've created the assignments with this in mind. Our in-class software studio sessions will cover the basics of the technical material, and there will be opportunities to ask for support. However, this is not an intro to programming class. It is ultimately your responsibility to learn what you need to know to complete the assignments. Refer to the [Resources](../resources/) page for learning materials.

### Setup

- A screen reader. Good options are: VoiceOver (built into macOS),  NVDA (free for Windows)
- A text editor, such as VS Code
- Firefox or Chrome, with developer tools
